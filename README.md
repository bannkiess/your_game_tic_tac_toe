# Tic Tac Toe

A simple tic tac toe game in plain HTML, CSS and JavaScript. No build step or dependencies.

## Features
- 2 player mode
- Play vs computer (unbeatable minimax AI)
- Score tracking for X, O and draws
- Highlights the winning line
- Works on mobile and with the keyboard

## Run it
Open `index.html` in your browser.

## Host it on GitHub Pages
1. Push these files to a GitHub repo
2. Go to **Settings → Pages**
3. Set the source to your main branch and root folder
4. Your game goes live at `https://<your-username>.github.io/<repo-name>/`
